# Running this client with an AI agent

For a guided path to getting the public Farcaster client snapshot running in an
iOS Simulator — written for AI coding agents, useful to humans too — see Dan
Romero's community guide:

**[Farcaster Client Agent Guide](https://github.com/danromero/farcaster-client-agent-guide)**

It covers host preflight checks, dependency bootstrap, an opt-in
credentials-free Firebase launch guard, and verification that the simulator is
really rendering the current checkout. The guide is independent and
community-maintained; it is not part of this repository.
