# Design System

Farcaster Mobile uses [react-native-tailwindcss](https://tvke.github.io/react-native-tailwindcss/) – a React Native port of [Tailwind](https://tailwindcss.com/) – for styling components. It should be noted that due to differences between platforms, the React Native port varies slightly (see [translations](https://tvke.github.io/react-native-tailwindcss/translations.html) and [special cases](https://tvke.github.io/react-native-tailwindcss/special-cases.html)) from the web version of Tailwind; but the vast majority of functionality works identically.

## `ThemeProvider` + `useTheme`

Rather than importing selectors directly from Tailwind, we have [a custom ESLint rule](https://github.com/merkle-manufactory/mobile/blob/main/src/contexts/ThemeProvider.tsx) to ensure styles are only accessed through a [`useTheme`](https://github.com/merkle-manufactory/mobile/blob/main/src/contexts/ThemeProvider.tsx) hook whose only purpose is to expose a theme object generated by `ThemeProvider`. In addition to preloading custom fonts and observing the user's preferred color scheme, the `ThemeProvider` prdecorates the `tw` object exported by `react-native-tailwindcss` with additional selectors. Currently, we are just adding a few custom styles to define text and border colors (e.g. `textDefault`, `textMuted`, `borderDefault`). We take this approach rather than [extending/overriding colors](https://tvke.github.io/react-native-tailwindcss/customization/customizing-colors.html) through `tailwind.config.js` for the following reasons:

1. Appending these properties within `ThemeProvider` gives us type safety and autocomplete without needing to add and maintain custom Typescript declarations.
2. While web can leverage media queries to declare context-aware styles (e.g. [dark mode](https://tailwindcss.com/docs/dark-mode)), React Native requires that we determine this information manually at runtime (e.g. [`useColorScheme`](https://reactnative.dev/docs/usecolorscheme)). Defining colors within `ThemeProvider` gives us a place for this logic.

## Basic Usage

Below is a basic example showing how we would use Tailwind (via `useTheme`) to style a button with horizontal margin of 1rem ([4px](https://tvke.github.io/react-native-tailwindcss/customization/customizing-spacing#default-spacing-scale)), vertical margin of 2rem ([8px](https://tvke.github.io/react-native-tailwindcss/customization/customizing-spacing#default-spacing-scale)), padding of 1rem ([4px](https://tvke.github.io/react-native-tailwindcss/customization/customizing-spacing#default-spacing-scale)), background color mapped to our custom `bgAction` style (`backgroundColor: '#8367CB'`), a border radius of [4px](https://tvke.github.io/react-native-tailwindcss/borders/border-radius.html) wrapping text that is centered and uses our custom `textInverted` color (i.e. black if the user is in dark mode, otherwise white). The example assumes that a `ThemeProvider` has been injected at the top of the React tree.

```jsx
const Widget = () => {
  const t = useTheme();

  return (
    <View style={[t.mX4, t.mY8, t.p4, t.bgAction, t.rounded]}>
      <Text style={[t.texts.inverted, t.textCenter]}>My Widget</Text>
    </View>
  );
};
```
